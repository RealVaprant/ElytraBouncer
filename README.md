# Elytra Bouncer
ⓘ Generated by AI; proofread by human.

Elytra Bouncer is a client-side Fabric mod for Minecraft 1.21.11 that assists repeated elytra bouncing while the configured Jump key is held.

## Features

- Keeps the normal Jump input active through ground contact after gliding has started.
- Briefly releases Jump after the bounce lifts the player so another bounce can register.
- Clears Jump input while chat or any other screen is open.
- Uses normal client key input without directly changing player position or velocity or sending packets.

## Installation

1. Install Fabric Loader for Minecraft 1.21.11.
2. Install Fabric API for Minecraft 1.21.11.
3. Optionally install Mod Menu to change the Enabled setting in-game.
4. Place `ElytraBouncer-1.0.0.jar` in the `.minecraft/mods` directory.
5. Launch Minecraft with the Fabric profile.

## Usage

Hold the Jump key while gliding and through ground contact. The mod briefly releases Jump after the bounce lifts you, then continues assisting while the key remains held.

Jump input is cleared whenever a screen is open, so holding the key while chatting or using a menu will not make the player jump or ascend.

## Configuration

With Mod Menu installed, open Elytra Bouncer's config screen to enable or disable the mod. The setting defaults to enabled and is saved in `.minecraft/config/elytra-bouncer.properties`.
